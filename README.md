<h1> Explicando o Jogo </h1>

O nosso jogo é um Quiz interativo com 15 perguntas relacionadas a Brusque - SC, envolvendo perguntas sobre aspectos culturais e turísticos da cidade. O mesmo apresenta sessões de dicas para caso qualquer pessoa tenha dificuldade na resolução de problemas tenha um norte a seguir.
