## Explicando o jogo

O **BrusQUIZ** é um quiz interativo com 15 perguntas relacionadas à cidade de **Brusque - SC**.

As perguntas envolvem aspectos culturais, históricos e turísticos da cidade. O jogo também possui uma seção de dicas, ajudando o jogador caso ele tenha dificuldade em responder alguma pergunta.
